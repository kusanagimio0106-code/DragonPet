✏️ Soạn câu hỏi
Câu hỏi sửa ở đây chỉ lưu tạm trên máy này để chạy thử, game của bé chưa đổi. Khi ưng ý, bấm 📋 Xuất code, dán vào file questions.json trên GitHub rồi Commit thì máy nào mở game cũng thấy bản mới.

📋 Code câu hỏi (questions.json)

  1. Bấm Copy bên dưới.
  2. Vào repo GitHub, mở file questions.json (chưa có thì Add file → Create new file, đặt tên questions.json).
  3. Bấm biểu tượng bút chì để sửa, chọn hết (Ctrl + A), dán đè (Ctrl + V).
  4. Bấm Commit changes, đợi 1–2 phút rồi tải lại trang game.
